## 1. 제품 개요

### 1.1 비전
작은 실천을 **매일** 이어가도록, 성취를 **눈에 보이는 보상(칭찬 도장·스티커판)**으로 바꿔주는 따뜻한 습관 앱.

### 1.2 문제 정의
- 기존 할 일/습관 앱은 "완료=체크"에서 끝나 **성취감·지속 동기**가 약하다.
- 숫자·통계 중심이라 부담스럽고, 며칠 놓치면 죄책감으로 이탈한다.

### 1.3 해결 방식
- 할 일을 완료하면 **칭찬 스티커**가 붙고, 판이 차면 **"참 잘했어요" 도장**이 찍힌다(어릴 적 도장 받던 경험 차용).
- 쉬어가도 **자책 대신 위로**하는 톤(슬럼프 케어, 부드러운 문구).
- 목표를 이루면 **보관(도장판째로 기록)**해 언제든 다시 꺼내 본다.

### 1.4 타깃 사용자
- 습관·루틴을 만들고 싶지만 딱딱한 생산성 앱에 지친 20~40대.
- 시각적 보상·귀여운 경험에 동기부여되는 사용자.
- "여행 준비", "자격증", "건강" 등 단발 목표를 챙기려는 사용자.

### 1.5 핵심 가치 제안
1. **모으는 재미** — 스티커·도장이 쌓이는 수집형 동기부여.
2. **따뜻함** — 칭찬·위로 중심의 카피와 AI 코칭.
3. **가벼움** — 로그인 후 오늘 할 일 하나만 해도 성공.

## 3. 핵심 컨셉 — 칭찬판(도장판)

- **스티커판(칭찬판)은 목표(꿈) 단위**로 존재한다.
- 그 목표의 할 일을 하나 완료할 때마다 **스티커 1개** 적립.
- 판의 칸 수(`cap`)를 모두 채우면 **도장 1개**를 찍고 판을 새로 시작.
- 판의 칸 수 = **그 목표의 할 일(세부 목표) 개수** (1~100). 할 일을 더하면 칸도 늘어난다.
- 6가지 테마: 🌳 나무 · 🍇 포도 · ⭐ 별 · 🌸 꽃밭 · 🎈 풍선 · 🌈 무지개 (개수에 맞춰 슬롯 자동 배치).
- **단일 진실 원천 원칙**: 스티커/도장 수는 항상 "실제 완료한 할 일 수"에서 재계산(`reconcileBoard`)해 어긋나지 않는다.

## 4. 주요 기능

### 4.1 오늘 탭 (Today)
- 날짜 네비게이터(◀ 날짜 ▶) + **달력 날짜 선택기**로 과거·미래(약 1년) 이동.
- **미래 할 일 미리 적기**: 내일·모레 등 앞 날짜에 할 일을 미리 등록 → 그날 자동으로 노출.
- **오늘의 나무**: 완료 비율에 따라 자라는 시각 피드백.
- **할 일 입력**(상단 고정 sticky) + 추가 시 응원 토스트.
- **추천 칩**: 이번 달에 3회 이상 직접 적은 할 일을 입력칸 위에 작게 추천(탭 시 즉시 추가).
- **인라인 수정**: 할 일 텍스트를 탭해 바로 편집(Enter 저장 / Esc 취소). 목표 연결 할 일은 목표명과 함께 갱신.
- **완료 체크**: 탭 시 팝 애니메이션 + 칭찬 스티커 적립.
- **내일로 미루기**, **삭제(되돌리기 5초)**.
- **슬럼프 케어**: 3일 이상 쉬면 위로 카드 + AI 응원.
- 목표에 연결된 할 일은 오늘 목록에 함께 뜨되 **목표 색으로 구분**.

### 4.2 목표(꿈) 탭 (Dreams)
- 카테고리 템플릿(여행/공부/자격증/취업/이직/건강/소소한 행복/자유) + **커스텀 카테고리**.
- 목표별: 아이콘/이모지, 색, 테마, **디데이(카운트다운)**, 세부 할 일(매일/한 번).
- **색·칭찬판 모양은 생성 후에도 변경 가능** — 칭찬판(카드 뒷면)의 "🎨 색·칭찬판 모양 바꾸기".
- 목표 색은 칭찬판 빈칸 테두리에도 반영된다.
- **매일(daily)**: 매일 새로 생성, 이월 없음. **한 번(once)**: 미완료 1건을 오늘로 이월(중복 없음).
- **칭찬판** 표시(테마별 일러스트 + 스티커 + 도장).
- **마치기(보관)**: 목표를 수동으로 완료 처리 → 기록 탭 "이룬 목표"로 이동(읽기 전용).
- 이름/할 일 편집, 접기/펼치기.
- 지난 날짜 완료 토글: **최근 7일 요일 스트립**으로, **'매일' 할 일에만** 제공.
  (7일보다 오래된 날짜, '한 번' 할 일의 과거 완료 처리는 미구현 — §11 참고.
   목표 카드의 달력 팝업은 디데이 선택 전용이며 과거 날짜는 선택할 수 없다.)

### 4.3 기록 탭 (Records)
- 통계 3종: **이룬 목표 · 진행 중 목표 · 모은 스티커**.
- 최근 2주 **잔디**(일별 완료 히트맵).
- **이룬 목표** 목록: 카드 펼치면 **다 모은 칭찬판(옅은 회색 음영) 위에 "참 잘했어요" 도장이 크게 중앙**에, 목표의 할 일 목록, **다시 진행하기(복원)**.

### 4.4 도장 시스템
- 6종 도장 변형: 참 잘했어요 · Best · Good · 축하해요 · 최고예요 · 대단해요.
- 꽃잎(스캘럽) 테두리 + 가운데 아이콘(엄지척 등) + Jua 폰트 문구.
- 판 완성 시 골드 축하 모달에서 도장이 "쾅" 찍히는 애니메이션(`stampDown`).

### 4.5 AI 코칭 (Claude)
- 상황별 메시지: **응원(encourage) · 슬럼프 케어(slump) · 주간 회고(review) · 축하(celebrate)**.
- 키 미설정·오류·비정상 응답 시 **하드코딩 폴백**으로 안전하게 대체(사용자에 에러 노출 금지).

### 4.6 알림 (Reminder)
- 매일 지정 시각 로컬 알림(브라우저 Notification / SW).

### 4.7 설정 (Settings)
- 리마인더 시각, 백업 불러오기, **관리자 모드 토글** 등.

### 4.8 관리자 모드 (Admin)
- 관리자 이메일(서버 `ADMIN_EMAILS` 검증)만 노출.
- 토글 시 **메인 화면 전체가 전체 사용자 데이터 뷰**로 전환(검색, 사용자별 목표/도장/스티커/할 일/원본 JSON).

### 4.9 PWA / 네이티브
- 홈 화면 설치(매니페스트·아이콘·apple-touch). 오프라인 캐시는 개발 중 이슈로 현재 비활성(안정화 후 재도입).
- **로컬 캐시 즉시 표시**: 재접속 시 마지막 상태를 즉시 렌더하고 백엔드는 백그라운드 동기화(콜드 스타트 체감 제거).
- **Capacitor** iOS/Android 래핑 준비. **iOS 홈 화면 위젯**(WidgetKit + App Group)으로 오늘 할 일 + 칭찬판 진행도 표시 코드 준비(`frontend/ios-native/`).

## 5. 대표 사용자 흐름

1. **온보딩**: 구글 로그인 → (목표 0개면) 목표 탭으로 안내 → 첫 목표 생성.
2. **매일 루틴**: 앱 열기 → 오늘 탭 → 할 일 완료 체크 → 스티커 적립(토스트) → 판 완성 시 도장 + 축하.
3. **목표 달성**: 목표의 할 일 모두 완료 → "다 이뤘어요" 안내 → 마치기 → 기록 탭 이룬 목표에 도장판째 보관.
4. **회복**: 며칠 쉼 → 슬럼프 카드 → 가장 쉬운 것 하나부터 다시.

## 7. 디자인 / UX 원칙

- **브랜드**: 이름 "여기붙여"(스티커를 여기 붙여). 워드마크는 둥근 **Jua** 폰트 + 첫 '여'의 ㅇ을 **스티커**로 표현.
- **색**: 파스텔 그린 팔레트(주색 `#46B97C`), 카드/그림자/라운드 토큰화(CSS 변수).
- **앱 아이콘**: "참 잘했어요" 도장(꽃잎 테두리+엄지척) · 파스텔 연두 배경.
- **폰트**: 본문 Pretendard, 포인트 Jua.
- **톤앤매너**: 칭찬·위로·응원. 자책 유발 금지.
- **모션**: 완료 팝, 도장 쾅, 빈 상태 새싹 등 은은한 생동감. `prefers-reduced-motion` 대응.
- **접근성**: 키보드 focus-visible, 안전영역(노치/홈바) 대응, `prefers-reduced-motion` 대응.
- **대비**: 흰 글자·아이콘을 얹는 초록은 파스텔 초록(`--primary`)이 아니라 별도 토큰
  `--on-primary`(#1f7a4c, 5.32:1) / `--on-primary-l`(#25834f, 4.73:1)을 쓴다 — 버튼·칩·토글·완료 체크·잔디 숫자 모두 WCAG AA 통과.
  장식용 초록은 브랜드 유지를 위해 그대로 둔다.
- **배경**: 배경 그라디언트는 쓰지 않는다. `body`는 `--bg`, `header`는 `--primary-soft`,
  스플래시는 `--on-primary` 평면색. 스플래시의 흰 워드마크 5.32:1 · 힌트 4.66:1 로 AA 통과.
  남은 미달 1곳: 헤더의 `.appver` 버전 라벨 4.11:1(§11).

## 8. 기술 스택 / 아키텍처

## 9. 비기능 요구사항

- **성능**: 재접속 즉시 표시(로컬 캐시), 정적 FE CDN 서빙.
- **신뢰성**: 상태 저장 낙관적 동시성 + 언로드 시 keepalive flush로 미저장 편집 보호.
- **보안**: 사용자 데이터는 백엔드 저장, 관리자 접근 서버 검증. 코드 식별자(appId `com.muruk.app`·App Group) 고정.
- **접근성/국제화**: 한국어 기본, 접근성 기본 준수.
- **개인정보**: 구글 계정 식별자·목표/할 일 데이터 최소 수집.

## 11. 미해결 / 향후 과제

- **지난 날짜 완료**: 7일보다 오래된 날짜, '한 번' 할 일의 과거 완료 처리(진짜 달력 기반 토글).
- **헤더 `.appver` 대비**: 버전 라벨이 4.11:1로 AA(4.5:1) 미달. `--muted`를 조정하면
  앱 전체에 번지므로 이 라벨만 별도 색을 줄지 판단 필요.
- **다크모드·반응형**: `prefers-color-scheme` 미대응, 브레이크포인트 없음(480px 고정).
- 마스코트 캐릭터 확정 및 도장 세트(표정·포즈) 확장.
- 워드마크 ㅇ-스티커 최종 형태 확정(A: ㅇ을 스티커로 / B: ㅇ 안에 작은 스티커).
- 소셜/공유(도장판 공유), 통계 심화, 다국어.
