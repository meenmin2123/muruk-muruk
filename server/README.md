# 작심 ↔ 노션 동기화 서버

앱(브라우저)은 노션 토큰을 가질 수 없어요(노출·CORS). 그래서 이 작은 서버가 토큰을 들고
앱과 노션 사이를 중계합니다.

```
[작심 앱] → [이 서버(토큰 보관)] → [Notion API]
```

## 1. 노션 인테그레이션(토큰) 만들기
1. https://www.notion.so/my-integrations 접속 → **New integration** 생성
2. 이름 아무거나(예: 작심), 워크스페이스 선택 → 저장
3. **Internal Integration Secret** 복사 (`ntn_...` 로 시작)

## 2. DB를 인테그레이션에 공유
아래 두 DB(또는 상위 "작심" 페이지)를 열고 → 우측 `•••` → **Connections(연결) → 만든 인테그레이션 추가**
- 작심 · 목표
- 작심 · 할일

> 공유를 안 하면 서버가 그 DB를 못 읽어요(404/권한 오류).

## 3. 서버 실행 (Node 18+ 필요, 설치 패키지 0)
```bash
cd "server"
NOTION_TOKEN=ntn_여기에붙여넣기 node notion-sync-server.mjs
```
실행되면: `✅ 작심 동기화 서버 실행: http://localhost:8787`

데이터소스 ID는 이미 코드에 기본값으로 박혀 있어요(필요하면 환경변수 `DREAM_DS`, `TODO_DS`로 교체).

## 4. 앱에서 동기화
1. 앱을 **http로** 열기 (file:// 아님):
   ```bash
   cd ..        # index.html 있는 폴더
   python3 -m http.server 8000
   ```
   → http://localhost:8000 접속
2. 📈 기록 탭 → **☁️ 노션 동기화** 카드
   - 서버 주소가 `http://localhost:8787` 인지 확인
   - **노션에 올리기** : 지금 앱 데이터를 노션에 씀(이미 올린 항목은 갱신)
   - **노션에서 받기** : 노션 내용을 앱으로 가져옴(현재 앱 데이터 대체)

## 5. (선택) 구글 로그인 + 사용자별 저장 켜기
로그인한 사람마다 데이터를 따로 저장하려면:

1. **노션 두 DB에 "사용자" 텍스트 속성 추가**
   - `작심·목표`, `작심·할일` 각각에 `사용자`라는 **텍스트(rich text)** 속성을 추가하세요.
   - (속성 이름을 바꾸고 싶으면 `USER_PROP` 환경변수로 지정)
2. **구글 OAuth 클라이언트 ID 발급**
   - https://console.cloud.google.com → API 및 서비스 → **사용자 인증 정보** → **OAuth 클라이언트 ID 만들기** → 유형 **웹 애플리케이션**
   - **승인된 자바스크립트 원본**에 앱 주소 등록 (예: `http://localhost:8000`, 배포 도메인)
   - 발급된 **클라이언트 ID**(`...apps.googleusercontent.com`)를 복사
3. **앱에 클라이언트 ID 넣기**
   - `index.html` 상단 스크립트의 `AUTH.GOOGLE_CLIENT_ID` 값에 붙여넣기
4. **서버에 같은 클라이언트 ID 넣고 실행**
   ```bash
   NOTION_TOKEN=ntn_xxx GOOGLE_CLIENT_ID=xxx.apps.googleusercontent.com node notion-sync-server.mjs
   ```

이렇게 하면: 앱이 로그인 → 구글 ID 토큰을 서버에 전달 → 서버가 토큰을 검증하고
그 사용자(`sub`)의 데이터만 노션에서 올리고/받습니다. 로그인 후엔 변경 시 **자동 저장**돼요.

> `GOOGLE_CLIENT_ID`를 비워두면 검증 없이 **단일 사용자 모드**(예전처럼 전체 공유)로 동작합니다.

## 동작 메모 (v1)
- **올리기(push)**: 꿈→`작심·목표`, 할 일→`작심·할일`(세부목표·반복·칭찬스티커·달성도장 포함). 각 항목의 노션 id를 앱이 기억해 다음엔 갱신.
- **받기(pull)**: 노션의 목표/할일을 읽어 앱 상태를 재구성. 세부목표(목표 레이어)와 스티커 개수까지 복원.
- 아직 **삭제 동기화는 없음**(앱에서 지운 항목의 노션 행은 남음). 충돌 해결형 양방향 동기화는 다음 단계.

## 클라우드 배포(나중에)
이 핸들러 로직을 Vercel/Netlify 서버리스 함수로 옮기고 `NOTION_TOKEN`을 환경변수로 넣으면
로컬 서버 없이도 어디서나 동기화돼요.
